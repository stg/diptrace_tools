DipTrace Part Database
==========================

Starting the program
--------------------
Windows: double-click "Launch Part Database.cmd".
macOS: double-click "Launch Part Database.command".
Linux: run sh "Launch Part Database.sh" from this folder.
Install Python and the dependencies first; see the root README for setup.
Files open with your system's default application for that file type.

What it does
------------
Scans a base folder and its subfolders for DipTrace binary schematic files
(.dch), then builds a searchable BOM database: part Name, Value and
Pattern, plus the filename and exact RefDes of every use. Schematics are
never changed. XML exports are not needed for this tool.

Getting started
---------------
1. Open Tools -> Settings. Select your base folder and the fields to search:
   Name, Value, Pattern and/or Filename. Save.
2. Click Refresh database (F5). The first scan reads every schematic; later
   refreshes read only new or modified files and remove deleted files.
3. Type your search. All words must match; letter case does not matter.
4. Expand a result to see its filenames and RefDes. Double-click a filename
   to open that schematic in its usual application.

Both programs support wildcards: * matches any text, # matches one or more
digits, and ? matches one character. For example, Board_R#.dch finds numbered
revisions. Use a backslash for literal symbols: \*, \# or \?.

The last refresh time is shown above the search box. Refresh errors appear
in the log. Tools -> Settings also controls whether results start expanded.
Your settings and the database are saved beside the program.

Edit -> Focus filter (Ctrl+F) selects the filter text. Copy selected rows
(Ctrl+C) copies the displayed columns. File -> Reload (Ctrl+R) reads the
saved database again; Refresh database (F5) scans your schematic folder.

Locations
---------
Double-click the Location column to enter a free-text storage label, such as
"Cabinet 2, drawer 7". A location belongs to the part's Name/Value/Pattern
combination and is shared across all its schematic uses. Clear the cell to
remove the label. Locations save automatically in part_locations.json,
separately from the scan database, and are preserved by database refreshes.
Tools -> Open part locations opens that file. Reload after external edits.

Normalization
-------------
Normalization makes common part names and value notation easier to find.
Tools -> Open normalization rules opens this program's editable rules file.
Save changes, then refresh. Normalization affects the database, never your
schematic files. The repository README.md lists the shipped defaults;
Help -> Normalization rule reference explains custom rules and examples.
